# The Green Corner — Sale Presentation

A 20-slide deck for handing over or selling the Green Corner website and admin.

## Present it

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

Then use the preview URL.

## Controls

| Key | Action |
| --- | --- |
| `→` `Space` `Enter` | Next |
| `←` `Backspace` | Previous |
| `N` | Speaker notes |
| `O` | Overview grid |
| `P` | Print / save as PDF |
| `Home` / `End` | First / last slide |
| Swipe | Next / previous on a phone |

Print with landscape pages (one slide per page) if you need a PDF.

## What this deck does not invent

No phone number, hours, reviews, revenue, or sale price. Those stay a conversation. Menu names and prices on the menu slide are the owner-confirmed list.
